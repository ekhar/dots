# Neovim configuration

This is a LazyVim-based configuration.

- Keep custom plugin specs in `lua/plugins/`.
- Prefer LazyVim extras over duplicating plugin setup.
- Keep one picker and one explorer implementation.
- Keep `lazy-lock.json` synchronized and committed with plugin changes.
- Validate Lua with StyLua and run a headless LazyVim health check after changes.
